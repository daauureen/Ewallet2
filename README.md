# Ewallet2
## СТЕК ТЕХНОЛОГИЙ:
- Backend: Python 3 + Flask
- Шаблонизатор: Jinja2 (серверный рендеринг HTML-страниц)
- База данных и авторизация: Supabase (Postgres), подключение через библиотеку supabase-py
- Стилизация: Tailwind CSS через CDN (без сборки)
- Графики: Chart.js через CDN
- Деплой: Vercel (через serverless-функцию, нужен файл vercel.json)
